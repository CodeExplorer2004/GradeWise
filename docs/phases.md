# 分阶段交付

1. 工程底座（已交付）：Docker 服务、环境配置、日志和健康检查。
2. 数据与认证：关系模型、Faker 数据、JWT、四角色 RBAC。
3. 智能问数：Deep Agents 子智能体、LangGraph 固定工作流、SQL 安全门与 Redis 会话。
4. 前端 MVP：登录、对话、看板，Axios 拦截器与 ECharts。
5. 质量门：黄金问句、越权与恶意 SQL 测试、端到端验收。
6. P1（已交付）：多维统计、成绩分布、异常检测、波动与当前不及格预警、学生报告、权限范围学情简报和 AI 评语。
7. P2（已交付）：语音输入、透明规则风险预测、浏览器提醒、CSV/XLSX/JSON 导入与清洗、MCP SVG 导出、独立 Agent Protocol worker，以及任务查询/更新/取消。
8. 跨学年分析基线（已交付）：届别与考试类型兼容迁移、权限化分析筛选、四角色差异化界面、看板/洞察/风险/报告/异步任务/智能问数范围继承，以及跨年级/跨学年口径保护。

## 生产部署前置项

- 将当前内存 Agent Server 替换为生产部署并启用持久化、服务鉴权和可观测性。
- 将浏览器会话提醒扩展为经用户授权的站内信、邮件或企业消息渠道，并增加去重、退订和审计。
- 为导入增加模板下载、批次历史/回滚策略和更大数据量的队列化处理。
- 增加浏览器端 E2E、故障注入、负载测试和备份恢复演练。
