## 本轮修复

1. 将项目和示例环境的默认模型提供方改为通义千问。
2. SQL 函数白名单补充安全的 `CASE/IF` AST 节点，恢复及格率条件聚合。
3. 为参数化字面量绑定布尔、整数、浮点、日期和字符串类型，修复 PostgreSQL `AVG(text)`。
4. 根目录 `.env` 可在项目根目录或 `backend` 目录启动时正确加载。
5. 对外展示 SQL 使用 `:value_n`，不再暴露驱动内部的 `%(value_n)s` 格式。
6. FastAPI 关闭时主动释放 Redis 和两个数据库连接池。
7. ECharts 从 5.x 升级到 6.1.x，消除已公开的中等级 XSS 公告。
8. TDesign 与 ECharts 改为按需加载；主 JS 从约 1.45 MB 降至约 244 KB，主 CSS 从约 458 KB 降至约 92 KB。
9. 增加前后端 `.dockerignore`，前端构建上下文从约 68 MB 降到 KB 级。
10. 前端 Docker 构建改用 `package-lock.json` 与 `npm ci`。
11. 新增确定性成绩分布、z-score 异常、跨考试同科波动和最新不及格记录查询。
12. 新增预警分析与报告生成子智能体，并通过 LangGraph 固定链生成学生报告和权限范围学情简报。
13. 修复 SQLGlot 将 `AND/OR/NOT` 布尔运算节点识别为函数而被白名单误拒的问题。
14. 报告数据发送模型前移除姓名；报告类型和标题由服务端确定，避免模型补造时间范围。
15. 在原数据看板内接入成绩分布、学情关注列表和 AI 报告，不增加业务页面。
16. 新增透明规则风险模型、风险原因说明和持久化快照；风险 Agent 只解释，不改变确定性分级。
17. 新增 CSV/XLSX/JSON 成绩导入、Unicode 清洗、校内实体匹配、边界校验、去重和批次审计。
18. 新增 Web Speech API 中文语音输入和浏览器学情通知入口。
19. 新增独立图表 MCP 容器，后端与渲染端双重白名单校验并支持 SVG 导出。
20. 新增独立 Agent Protocol worker，并将批量报告、批量预警注册为 Deep Agents `AsyncSubAgent`。
21. 新增任务所有者 Redis 绑定、服务端证据生成、HMAC 脱敏、状态查询、更新和取消接口。
22. 修复中文图表标题写入 `Content-Disposition` 导致的 Latin-1 500 错误，改用 ASCII 回退名与 UTF-8 `filename*`。
23. 在原数据看板增加异步任务控制面，不增加第四个页面。
24. 将成绩分布从成绩人次改为最近一次考试学生均分人数，并显示考试名称与样本数。
25. 增加权限范围说明，同时为任课教师和班主任范围补充学年匹配条件。
26. 增加学情关注分类计数与分页接口，前端可查看所有记录而非仅前 8 条。
27. 将风险提醒改为可开启/关闭状态，并仅在高风险集合变化时通知；页面明确说明浏览器会话边界。
28. 重写 Faker 成绩生成模型，使学生跨科目、跨考试成绩更稳定；学校整体及格率约 95%，并保留少量受控预警样本。
29. 重建演示授课关系：每位任课教师固定一个学科，可教授多个班级；不再用轮转算法跨学科分配。

## 尚未完成或保留风险

- 当前 Agent worker 使用官方内存开发 Agent Server。协议与容器边界已验证，但生产环境仍需替换为持久化且带服务鉴权的部署。
- 当前自动提醒为浏览器通知，需要用户授权且仅在前端会话内工作；邮件、企业消息等外部通道尚未接入。
- ECharts 按需包约 579 KB，仍触发 Vite 500 KB 提示，但已包含柱状、折线、饼图和雷达图四类能力。
- 数据库当前由启动引导创建表和视图；正式生产发布前建议改为版本化 Alembic 迁移。
- 当前完成了接口与构建级端到端验证，尚未引入 Playwright 浏览器自动化。
- Windows 本地 Vite 因现有 `node_modules/.vite-temp` 写权限失败；独立 TypeScript 检查和 Docker 内生产构建均通过。
