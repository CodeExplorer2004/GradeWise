# GradeWise 最终演示运行手册

## 演示目标

在 8–10 分钟内证明三件事：四角色数据权限真实生效、智能问数受确定性安全边界约束、Agent 任务与工程质量具备可验证的可靠性。

## 演示前检查清单

- [ ] 仅使用 Faker 演示数据，不导入真实学生信息。
- [ ] 确认 Docker Desktop 可用，8080 或演示指定端口未被其他进程占用。
- [ ] 检查 .env 中 PostgreSQL 密码、只读密码和 JWT 密钥均为非默认强值。
- [ ] 执行 docker compose config --quiet。
- [ ] 执行 docker compose up --build --detach --wait --wait-timeout 240。
- [ ] 打开 /health/ready，确认 PostgreSQL 与 Redis 均为 ok。
- [ ] 用 academic01、teacher01、headteacher01、student01 各登录一次。
- [ ] 预先打开 [汇报架构图](demo-architecture.md) 和 [最新测试报告](test-report-2026-09-11.md)。
- [ ] 关闭浏览器自动翻译、密码填充和无关通知，页面缩放保持 100%。
- [ ] 在正式演示前执行 cd frontend，然后运行 npm run test:e2e，确认 7 项通过。

演示账号密码统一为 GradeWise123!。正式环境不得沿用该密码。

## 8–10 分钟演示脚本

| 时间 | 操作 | 讲解重点 |
| --- | --- | --- |
| 0:00–0:45 | 展示架构图 | 先讲“权限先于智能、规则决定执行、任务可追踪”三条主线。 |
| 0:45–1:45 | 以 academic01 登录，进入数据看板 | 展示全校 756 名学生范围，以及学年、年级、届别、班级、科目筛选。强调筛选只会收窄服务端授权范围。 |
| 1:45–3:00 | 进入智能问数，提问“最近3次考试各科平均分” | 展示确定性近期考试集合、结果表格和图表；说明未配置模型密钥时仍能走安全模板。 |
| 3:00–4:15 | 退出后依次登录 teacher01、headteacher01、student01 | 展示任课教师 84 人、班主任 42 人、学生 1 人的数据范围差异。说明权限由后端查询边界实现，不是前端隐藏。 |
| 4:15–5:15 | 展示越权与导入失败路径证据 | 展示任课教师请求未授权班级返回 403；说明非法导入行保留批次统计和逐行错误，不静默写入。 |
| 5:15–6:30 | 展示 Agent 任务区 | 讲解 PostgreSQL 任务账本、状态与尝试次数；worker 丢失状态后标记 interrupted，点击“重新执行”创建新 worker 执行但保留应用任务 ID。 |
| 6:30–7:30 | 展示安全与依赖工程 | 指出登录第 5 次失败返回 429、安全响应头、Nginx 版本隐藏、三套哈希锁、Docker 按锁安装和 CI 漏洞审计。 |
| 7:30–8:30 | 展示最新测试报告 | 收口到 149 项后端测试、7 项 Playwright、前端构建及六服务健康检查。 |
| 8:30–9:00 | 展示当前边界 | 主动说明精确断点恢复、生产令牌、压测、灾备、大文件队列和外部通知属于后续生产仿真，不冒充已完成。 |

## 演示中检查清单

- [ ] 每次切换角色都先退出登录，避免复用上一个账号的本地令牌。
- [ ] 先展示页面上的“权限范围”再展示统计数字。
- [ ] 问数使用确定性演示问题，避免依赖外部模型网络。
- [ ] 不在屏幕中展示 .env、JWT、数据库密码或模型密钥。
- [ ] 不现场停止共享容器来模拟中断；使用已验证的 E2E 用例或预置演示记录。
- [ ] 若图表动画未完成，先等待结果表格出现，再切换页面。

## 故障回退

| 现象 | 现场处理 |
| --- | --- |
| /health/ready 返回 503 | 保留页面，执行 docker compose ps，只说明依赖尚未就绪；不要跳过健康门。 |
| 智能问数外部模型不可用 | 改用“最近3次考试各科平均分”，走无模型密钥的确定性路径。 |
| Agent worker 无模型密钥 | 展示任务台账、中断识别与 Playwright 恢复用例，不宣称生成结果成功。 |
| 浏览器端口冲突 | 使用另一 Compose 项目端口并设置 PLAYWRIGHT_BASE_URL，不要停止来源不明的容器。 |
| 时间不足 | 保留架构图、四角色范围、一次确定性问数和最终测试报告四段。 |

## 演示后检查清单

- [ ] 退出演示账号并关闭含令牌的浏览器窗口。
- [ ] 若使用隔离 E2E 项目，执行 docker compose -p gradewise-e2e -f docker-compose.yml -f docker-compose.e2e.yml down --volumes --remove-orphans。
- [ ] 保留测试报告，不保留 Playwright trace、截图或临时导入文件。
- [ ] 汇报时将“当前边界”原样列出，避免把生产仿真事项描述为已交付。
