# 最近 X 次考试查询设计

## 目标

让包含“最近/近 X 次（场）考试”的成绩查询不再依赖模型临时生成 SQL，并在明细、平均分、趋势和不及格记录四类查询中使用同一个考试范围。

## 已确认行为

- 同时支持阿拉伯数字和常用中文数字，例如 `3`、`三`、`两`。
- 最近考试按 `exam_date DESC, exam_id DESC` 确定，考试不足 X 次时使用全部可见考试。
- 考试集合必须先受当前用户权限和显式班级、科目等过滤条件约束。
- 平均分由数据库直接聚合，并返回实际参与统计的考试数量。
- 明细、趋势、不及格记录必须只返回同一个最近考试集合。
- 此类查询的模式识别、SQL、审计、图表和答案使用确定性路径，避免模型额度或输出波动导致查询失败。

## 验收标准

- “最近3次考试各科成绩”只包含最近 3 场考试。
- “最近2次考试数学平均分”返回单个合并平均分，而不是每场一行。
- “最近3次考试语文平均分”和“近三次考试语文平均分”生成相同语义的安全 SQL。
- “近两次考试各科成绩趋势”只包含最近 2 场考试。
- “最近3次考试不及格记录”及其统计图使用相同的最近 3 场范围。
- X 大于现有考试数时不报错，并明确实际统计场数。
